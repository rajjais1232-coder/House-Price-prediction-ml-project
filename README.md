## Overview

This project trains multiple regression models on the [California Housing dataset](https://www.kaggle.com/datasets/camnugent/california-housing-prices), automatically selects the best-performing model via 5-fold cross-validation, and serves predictions through a clean Streamlit web UI.

**Key highlights:**
- Automated model selection across 4 regression algorithms
- Full scikit-learn preprocessing + estimator pipeline serialised to disk
- Pure-Python frontend built with Streamlit — no JavaScript required
- Interactive prediction form + data visualisation dashboard

## Dataset

**File:** `housing.csv` (California Housing dataset — 20,640 rows)

| Column | Type | Description |
|---|---|---|
| `longitude` | float | Block longitude |
| `latitude` | float | Block latitude |
| `housing_median_age` | float | Median age of houses in the block |
| `total_rooms` | float | Total number of rooms |
| `total_bedrooms` | float | Total number of bedrooms |
| `population` | float | Block population |
| `households` | float | Number of households |
| `median_income` | float | Median income (tens of thousands $) |
| `ocean_proximity` | string | Proximity to ocean (`<1H OCEAN`, `INLAND`, `ISLAND`, `NEAR BAY`, `NEAR OCEAN`) |
| `median_house_value` | float | **Target** — Median house value ($) |


**2. Create and activate a virtual environment (recommended):**

## Usage

### Step 1 — Train the model

```bash
python train_model.py
```

This will:
- Load `housing.csv`
- Run 5-fold cross-validation across 4 candidate models
- Print a comparison table of CV scores
- Save the best pipeline to `best_model.pkl`
- Export cross-validation metrics to `model_metrics.csv`

**Example output:**
```
[INFO] Loading data from: housing.csv
[INFO] Dataset shape: (20640, 10)
[INFO] Train: 16512 rows | Test: 4128 rows

[INFO] Running 5-fold cross-validation ...
  LinearRegression           R²=0.6477  RMSE=68,604
  Ridge                      R²=0.6478  RMSE=68,596
  RandomForest               R²=0.8171  RMSE=49,445
  HistGradientBoosting       R²=0.8256  RMSE=48,277

[INFO] Best model: HistGradientBoosting  (R²=0.8256)
[INFO] Test set — R²=0.8238  RMSE=48,058
[INFO] Saved best_model.pkl
```

### Step 2 — Launch the Streamlit app

```bash
streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`.

## Model Performance

Models evaluated using **5-fold cross-validation** on 80% of the dataset:

| Model | CV R² | CV RMSE |
|---|---|---|
| Linear Regression | 0.6477 | $68,604 |
| Ridge | 0.6478 | $68,596 |
| Random Forest | 0.8171 | $49,445 |
| **HistGradientBoosting ✅** | **0.8256** | **$48,277** |

**Final test set evaluation (held-out 20%):**

| Metric | Score |
|---|---|
| R² | **0.8238** |
| RMSE | **$48,058** |

The best model is selected automatically based on highest mean CV R² score.

## App Features

### 🔮 Predict Tab
- Sliders and number inputs for all 8 numeric features
- Dropdown for `ocean_proximity`
- Instant predicted median house value on click
- Contextual info: what percentile the prediction falls in vs. the training data

### 📊 Dashboard Tab
- **Dataset Overview** — shape, missing values, first 10 rows
- **Feature Distributions** — histograms with KDE for all 8 numeric features
- **Target Distribution** — histogram of `median_house_value`
- **Ocean Proximity** — bar chart of category counts
- **Model Comparison** — side-by-side horizontal bar charts for R² and RMSE across all 4 candidate models
